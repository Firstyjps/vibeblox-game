# Mystic Creature Simulator — Game Design (MVP)

> เอกสารนี้คือข้อตกลงของทีมว่าเกมทำงานยังไง ตัวเลขทั้งหมดอยู่ใน `src/shared/Config.luau` (ในนี้เป็นค่าเริ่มต้น ปรับได้)

## ภาพรวม
- **Genre:** Simulator · **ธีม:** Mystic Creature
- **แนวเล่น:** Semi AFK, PVE, Summon, Stage (โลก), Currency, Level, Rebirth
- **เกมอ้างอิง (แนวการเล่น):** แนว anime simulator — ผู้เล่นตีมอนเอง มี summon สุ่มกาชาช่วยตี มีหลายโลก
- **Art ที่อยากได้:** สดใส สีจัด โลกการ์ตูน ต้นไม้เขียวสด ท้องฟ้าใส (แนว anime adventure)
- **Art ที่ไม่อยากได้:** รกตา สีปนกันจนดูไม่ออกว่าอะไรสำคัญ
- เราทำเกมของเราเอง — ไม่ลอกชื่อ ตัวละคร หรือ asset จากเกมอื่น

## Core loop
1. เข้าเกมครั้งแรก → **เลือกเผ่า** (เลือกได้ครั้งเดียว)
2. ตีมอนในโลก → ได้ **Coins + XP** (บางทีได้ **Gems**)
3. ใช้ Gems **สุ่ม Summon** → ใส่ทีมได้ 3 ตัว ช่วยตีมอนรอบตัวอัตโนมัติ (ยืน AFK ได้)
4. ใช้ Coins **อัปค่าพลัง** (Damage / HP)
5. ทำ **ภารกิจโลก** (ฆ่ามอนครบ + ชนะบอส) → จ่าย Coins เปิด **โลกถัดไป**
6. เลเวลถึงเกณฑ์ → **Rebirth** รีเซ็ต Coins + Level แลกตัวคูณถาวร

## เผ่า (เลือกตอนเริ่ม)
| เผ่า | จุดเด่น |
|---|---|
| Elf | ระยะตีไกล |
| Dragon | HP สูง |
| Vampire | ดูดเลือดตอนตี |
| Lich | ดาเมจแรง แต่ HP ต่ำ |
| Fairy | ตีเร็ว เดินเร็ว |

- เปลี่ยนเผ่าไม่ได้ (เวอร์ชันแรก) · **dev เปลี่ยนได้อิสระ** ผ่านปุ่ม Dev (ใน Studio ทุกคนเป็น dev, เกมจริงใส่ UserId ใน `Config.DEV_USER_IDS`)
- ท่าพิเศษของแต่ละเผ่า → ทำรอบหลัง

## การต่อสู้
- ผู้เล่นเป็นคนสู้หลัก: กดปุ่มตี / คลิก / ปุ่ม F → ตีมอนที่ใกล้สุดในระยะ (server เลือกเป้าเอง)
- มอนตีกลับ ผู้เล่นตายได้ → เกิดใหม่ที่จุดเริ่มของโลกนั้น ไม่เสียของ
- มอนใช้ร่วมกันทั้งเซิร์ฟ — ทุกคนที่ทำดาเมจได้รางวัลตามสัดส่วน (ทำดาเมจ ≥ 10% ถึงนับภารกิจ)
- บอสเกิดใหม่ทุก 60 วินาที

## Summon
- สุ่มด้วย **Gems** (50 ต่อครั้ง) · ใส่ทีมได้ **3 ตัว** (เพิ่มด้วย Robux ทีหลัง — ยังไม่ทำ)
- Summon ตามผู้เล่น และตีมอนในรัศมีรอบตัวผู้เล่นเอง
- ได้ XP เมื่อเจ้าของฆ่ามอน → เลเวลขึ้น ดาเมจขึ้น

| สาย | บทบาท (MVP) |
|---|---|
| แทงก์ | ตีเบา + **ลดดาเมจที่เจ้าของโดน** (รวมกันสูงสุด 50%) — ดึงมอนให้ตีตัวเองทำรอบหลัง |
| แอสซาซิน | ตีแรง เร็ว เป้าเดียว |
| เวทย์ | ตีเป็นวง (AoE) |

| ระดับ | โอกาส | ตัวคูณพลัง |
|---|---|---|
| Common | 60% | x1 |
| Rare | 25% | x1.6 |
| Epic | 10% | x2.6 |
| Legendary | 4% | x4.2 |
| Mythic | 1% | x7 |

## โลก (Stage)
| # | โลก | มอน | บอส | เปิดด้วย |
|---|---|---|---|---|
| 1 | Enchanted Forest (ป่า) | Slime, Shadow Wolf | Ancient Golem | — |
| 2 | Inferno (นรก) | Fire Imp, Shadow Wolf | Ancient Golem (แรงกว่า) | ภารกิจโลก 1 + 2,500 Coins |
| 3 | Heaven (สวรรค์) | — ทำรอบหลัง — | | |

- ภารกิจโลก = ฆ่ามอน N ตัว + ชนะบอสของโลก → ได้ Gems โบนัส
- เดินทางผ่าน **Portal** (กด E / แตะ)

## Level / Rebirth
- ผู้เล่นและ summon มีเลเวลทั้งคู่ · เลเวลผู้เล่นเพิ่มดาเมจและ HP
- **Rebirth:** ต้องถึง Lv.15 → รีเซ็ต **Coins + Level** → ได้ **+25% Coins/XP ถาวร** ต่อครั้ง
- Gems, summon, อัปเกรด และโลกที่เปิดแล้ว **ไม่หาย**

## สกุลเงิน
- **Coins** — จากมอน ใช้อัปค่าพลัง + เปิดโลก
- **Gems** — จากบอส / ภารกิจ / ดรอปจากมอน 5% ใช้สุ่ม summon (เริ่มเกมได้ 100)

## ขอบเขต MVP
- ✅ 2 โลก, มอน 3 แบบ, บอส 1 แบบ, ตู้สุ่ม summon 1 ตู้, เลเวล + rebirth พื้นฐาน
- ✅ โมเดลชั่วคราวทำจาก Part (สีตามเผ่า / ระดับ) — เปลี่ยนเป็นโมเดลจริงทีหลัง
- ❌ ยังไม่ทำ: Robux, ท่าพิเศษเผ่า, โลก 3, ดึงมอนของแทงก์, offline reward

| ไฟล์ | หน้าที่ |
|---|---|
| `shared/Config.luau` | ตัวเลขสมดุลทั้งหมด (เผ่า, มอน, โลก, summon, ราคา) |
| `shared/Modules/Formulas.luau` | สูตรคำนวณ (ดาเมจ, HP, XP, ราคา) ใช้ทั้ง server และ UI |

| `shared/Modules/Ui.luau` | ตัวช่วยสร้าง UI (UIScale, ปุ่ม, panel) |
| `shared/Modules/RateLimit.luau` | จำกัดความถี่ remote |
| `server/Services/RaceService` | เลือกเผ่า, ปุ่ม dev, ใส่ค่าพลังให้ตัวละคร |
| `server/Services/ProgressionService` | ให้รางวัล, เลเวล, อัปเกรด, rebirth |
| `server/Services/WorldService` | สร้างแมพ, portal, ภารกิจโลก |
| `server/Services/EnemyService` | เกิดมอน/บอส, AI, ตาย/แจกรางวัล |
| `server/Services/CombatService` | ผู้เล่นตี, มอนตีผู้เล่น |
| `server/Services/SummonService` | สุ่ม, ใส่ทีม, summon เดินตาม/ตี |
| `client/Controllers/*` | HUD, แจ้งเตือน, เลือกเผ่า, ปุ่มตี + ตัวเลขดาเมจ, หน้า Summon, หน้าอัปเกรด/Rebirth |
