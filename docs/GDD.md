## 2. Core loop
```
เดินเข้าโซนมอนสเตอร์ → สัตว์เวทที่ติดตัว (สูงสุด 3 ตัว) ตีมอนอัตโนมัติ
      → ได้ Coins (+EXP ให้สัตว์)
      → ใช้ Coins สุ่มไข่ (Summon) ได้สัตว์ตัวใหม่/แรงกว่า → ใส่ทีม
      → ล้มบอสของด่าน → ปลดด่านถัดไป (Stage) → มอนแรงขึ้น เงินมากขึ้น
      → ติดด่าน → Rebirth: รีเซ็ต Coins/ด่าน แลกตัวคูณถาวร → ไปได้ไกลกว่าเดิม
```
- **Semi-AFK**: ยืนในโซนแล้วสัตว์ตีเองได้ แต่ผู้เล่นที่ "คลิกช่วยตี" จะได้เร็วกว่า (คลิก = ดาเมจเสริม)
- **PVE เท่านั้น** ใน MVP — ไม่มี PVP

## 3. ระบบ (MVP)
### 3.1 Currency
- **Coins** — ได้จากตีมอน ใช้สุ่มไข่/อัปเลเวล
- **Gems** — สกุลพรีเมียม ได้จากบอส/รางวัล (MVP ยังไม่ขายด้วย Robux)
- **Rebirth Tokens** — ได้ตอน Rebirth ใช้ซื้อบัฟถาวร (เฟสหลัง)

### 3.2 Creatures (สัตว์เวท)
- แต่ละตัวมี: `id`, ชื่อ, ธาตุ, ความหายาก, พลังพื้นฐาน, Level
- ความหายาก: Common · Rare · Epic · Legendary · Mythic
- ธาตุ (ไว้ทำแพ้ทาง เฟสหลัง): Fire · Water · Nature · Light · Shadow
- ทีมติดตัวสูงสุด 3 ตัว (ปลดเพิ่มได้ภายหลัง) · กระเป๋าเก็บสูงสุด 50 ตัว
- พลังทีม = ผลรวมพลังสัตว์ที่ติดตัว × ตัวคูณ Rebirth

### 3.3 Summon (สุ่มไข่)
- 1 ไข่ต่อ 1 โลก ราคาเป็น Coins · สุ่ม 1 / สุ่ม 3
- โอกาสเริ่มต้น (ไข่โลก 1): Common 70% · Rare 22% · Epic 6.5% · Legendary 1.4% · Mythic 0.1%
- **สุ่มที่ server เท่านั้น** · โชว์อัตราในเกมให้เห็นชัด

### 3.4 Stage / World
- MVP = **1 โลก 5 ด่าน** (ด่าน 5 = บอส) · ล้มบอส → ปลดโลก 2 (เฟสหลัง)
- มอนเกิดใหม่ทุก ~3 วิ · HP และ Coins ต่อตัวโตขึ้นตามด่าน

### 3.5 Level
- สัตว์ได้ EXP จากการตี → เลเวลขึ้น พลังเพิ่ม (เช่น +10%/เลเวล) · เลเวลตันตามความหายาก

### 3.6 Rebirth
- เงื่อนไข: ผ่านด่านบอสโลก 1 + มี Coins ตามที่กำหนด
- ผล: Coins และด่านรีเซ็ต · สัตว์ยังอยู่ · ได้ตัวคูณ Coins/พลังถาวร (+50% ต่อครั้ง)

## 4. UI (มือถือใช้ได้)
- HUD บน: Coins · Gems · ด่านปัจจุบัน
- ปุ่มด้านขวากลางจอ: กระเป๋าสัตว์ · Summon · Rebirth
- หน้าสุ่มไข่: อัตราดรอป + แอนิเมชันเปิดไข่
- เลี่ยงมุมซ้ายล่าง (จอย) และขวาล่าง (ปุ่มกระโดด) ตาม AGENTS.md

## 5. นอก MVP (ทำทีหลัง)
โลก 2-3 · ธาตุแพ้ทาง · Fuse/Evolve สัตว์ · Daily reward · Quest · Leaderboard · Trading · Gamepass/Dev Product · Roblox Group
