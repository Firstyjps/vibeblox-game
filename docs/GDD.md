# Mystic Creature Simulator — Game Design Doc (MVP)

> ชื่อเกมยังเป็นชื่อชั่วคราว · เอกสารนี้คือ "สิ่งที่ตกลงกันแล้ว" — จะเปลี่ยนอะไร แก้ไฟล์นี้ผ่าน PR
> ตัวเลขทั้งหมดเป็นค่าเริ่มต้น ปรับได้ใน `src/shared/Config.luau`

## 1. สรุปเกม
| หัวข้อ | ที่ตกลง |
|---|---|
| Genre | Simulator |
| Theme | Mystic Creature — ผู้เล่นเป็นสิ่งมีชีวิตเวท (เลือกเผ่า) + สัตว์เวทที่ **ออกแบบเอง** (ไม่ใช้ตัวละครจากอนิเมะหรือเกมอื่น) |
| Type | Semi-AFK · PVE · Summon · Stage · Currency · Level · Rebirth |
| แนวเกมที่อ้างอิง | [CHAINSAW] Anime Astral Simulator, [MINERS] Anime Breaker — ตีมอนเอง มีตัวช่วยสุ่มได้ ไล่ด่าน เปิดโลกใหม่ |
| Art ที่อ้างอิง | Anime Crusaders X, Anime Paradise — สีสด ตัวละครชัด อ่านง่าย โลกการ์ตูนสว่าง |
| Art ที่ไม่เอา / ไม่ให้เกิน | Anime Expeditions — รายละเอียดเยอะ เอฟเฟกต์รก ดาร์กเกินไป |
| Art ช่วงแรก | โมเดลชั่วคราว (Part) หรือโมเดลฟรีจาก Creator Store แล้วค่อยเปลี่ยนเป็นของทีม |

> เราทำเกมของเราเอง — ใช้เกมข้างบนแค่ดูแนวการเล่น/โทนสี ไม่ลอกชื่อ ตัวละคร หรือ asset

## 2. Core loop
```
เข้าเกมครั้งแรก → เลือกเผ่า (ได้ร่างกายตามเผ่า เช่น มังกรมีปีก)
→ เดินเข้าด่าน → ผู้เล่นตีมอน + สัตว์เวทในทีม (สูงสุด 3 ตัว) ช่วยตีอัตโนมัติ
      → ได้ Coins + EXP (ผู้เล่นและสัตว์)
      → เลเวลอัป → ได้ 3 Skill Points → อัป HP / พลังโจมตี / ความเร็ว / สกิลเผ่า
      → ใช้ Coins สุ่มไข่ ได้สัตว์ใหม่/แรงกว่า → ใส่ทีม
      → เคลียร์ด่าน → ปลดด่านถัดไป → ด่าน 5 ล้มบอส
      → Rebirth: รีเซ็ต Coins/ด่าน แลกตัวคูณถาวร + Rebirth Token → ไปได้ไกลกว่าเดิม
```
- **ผู้เล่นเป็นคนสู้หลัก** (กดปุ่มตี / คลิก / F) · **Semi-AFK** = ยืนเฉยๆ สัตว์ในทีมตีมอนรอบตัวให้เอง
- **PVE เท่านั้น** ใน MVP — ไม่มี PVP

## 3. ระบบ (MVP)

### 3.1 เผ่า (เลือกตอนเริ่มเกม)
| เผ่า | จุดเด่น | ร่างกายเพิ่ม (โมเดลชั่วคราว) |
|---|---|---|
| Elf | ตีได้ไกล | หูแหลม |
| Dragon | HP สูง | ปีก + เขา + หาง |
| Vampire | ดูดเลือดตอนตี | ผ้าคลุม + ปกคอ |
| Lich | ดาเมจแรง HP ต่ำ | มงกุฎกระดูกเรืองแสง |
| Fairy | ตีเร็ว เดินเร็ว | ปีกโปร่งใส + ประกาย |

- เลือกได้ครั้งเดียว · **dev เปลี่ยนได้อิสระ** ผ่านปุ่ม Dev (ใน Studio ทุกคนเป็น dev · เกมจริงใส่ UserId ใน `Config.DEV_USER_IDS`)

### 3.2 Skill Tree (ต่อเผ่า)
- เลเวลอัป 1 ครั้ง = **3 Skill Points**
- **ค่าพื้นฐาน** (ทุกเผ่า): HP · พลังโจมตี · ความเร็วเคลื่อนที่ (1 point = 1 ขั้น)
- **สกิลเผ่า** ปลดเมื่อถึง **Lv.10** — แต่ละเผ่ามี 2 สกิลเฉพาะ (ขั้นละ 3 points, สูงสุด 5 ขั้น)

| เผ่า | สกิล 1 | สกิล 2 |
|---|---|---|
| Elf | Eagle Eye — ระยะตีไกลขึ้น | Nature's Grace — ตีเร็วขึ้น |
| Dragon | Dragon Scales — โดนดาเมจน้อยลง | Dragon Might — ดาเมจแรงขึ้น |
| Vampire | Blood Thirst — ดูดเลือดมากขึ้น | Crimson Strike — โอกาสคริติคอล |
| Lich | Arcane Power — ดาเมจแรงขึ้น | Bone Ward — โดนดาเมจน้อยลง |
| Fairy | Pixie Dust — ได้ Coins มากขึ้น | Flutter — เดินเร็วขึ้น |

### 3.3 Currency
- **Coins** — ได้จากตีมอน ใช้สุ่มไข่ + เป็นเงื่อนไข Rebirth
- **Gems** — สกุลพรีเมียม ได้จากบอส/รางวัล (MVP ยังไม่ขายด้วย Robux · ยังไม่มีที่ใช้)
- **Rebirth Tokens** — ได้ตอน Rebirth ใช้ซื้อบัฟถาวร (ร้านบัฟ = เฟสหลัง)

### 3.4 Creatures (สัตว์เวท / Summon)
- แต่ละตัวมี: ชื่อ, **ธาตุ**, **ระยะ (ใกล้/ไกล)**, ความหายาก, พลังพื้นฐาน, Level
- ธาตุ: Fire · Water · Nature · Light · Shadow (แพ้ทาง = เฟสหลัง)
- ระยะ: **ใกล้** วิ่งเข้าไปตี ดาเมจสูง · **ไกล** ยืนใกล้เจ้าของแล้วยิง ดาเมจต่ำกว่า
- ความหายาก: Common · Rare · Epic · Legendary · Mythic (เลเวลตันตามความหายาก)
- ทีมติดตัวสูงสุด **3 ตัว** (ปลดเพิ่มด้วย Robux ภายหลัง) · กระเป๋าเก็บสูงสุด **50 ตัว**
- ได้ EXP เมื่อทีมฆ่ามอน → เลเวลขึ้น พลัง +10%/เลเวล
- พลังสัตว์ × ตัวคูณ Rebirth

### 3.5 Summon (สุ่มไข่)
- 1 ไข่ต่อ 1 โลก · จ่ายด้วย **Coins** · สุ่ม 1 / สุ่ม 3
- โอกาส (ไข่โลก 1): Common 70% · Rare 22% · Epic 6.5% · Legendary 1.4% · Mythic 0.1%
- **สุ่มที่ server เท่านั้น** · โชว์อัตราในเกมให้เห็นชัด

### 3.6 Stage
- MVP = **1 โลก (Enchanted Forest) 5 ด่าน**
- ด่าน 1–4: ฆ่ามอนครบตามจำนวน → ปลดด่านถัดไป · ด่าน 5 = **บอส**
- มอน 3 แบบ (Slime, Shadow Wolf, Fire Imp) + บอส 1 แบบ (Ancient Golem) · มอนเกิดใหม่ทุก ~3 วิ
- HP และ Coins ต่อตัวโตขึ้นตามด่าน · ล้มบอส → ปลดโลก 2 (เฟสหลัง)

### 3.7 Level
- ผู้เล่น: EXP จากการฆ่ามอน → เลเวลอัปได้ Skill Points
- สัตว์: ดู 3.4

### 3.8 Rebirth
- เงื่อนไข: ล้มบอสโลก 1 แล้ว + มี Coins ตามที่กำหนด (แพงขึ้นทุกครั้ง)
- ผล: **Coins และด่านรีเซ็ต** · เลเวล, skill, สัตว์ยังอยู่ · ได้ตัวคูณ Coins/พลังถาวร **+50% ต่อครั้ง** + Rebirth Token

## 4. UI (มือถือใช้ได้)
- HUD บน: Coins · Gems · Tokens · Level/EXP · ด่านปัจจุบัน · กล่องความคืบหน้าด่าน (ขวาบน)
- **ปุ่มเมนูด้านขวากลางจอ**: Summon · กระเป๋าสัตว์ · Skills · Rebirth (+ Dev)
- ปุ่มตี: ล่างกลางจอ (PC คลิกซ้าย / F)
- หน้าสุ่มไข่: อัตราดรอป + แอนิเมชันเปิดไข่
- เลี่ยงมุมซ้ายล่าง (จอย) และขวาล่าง (ปุ่มกระโดด) ตาม AGENTS.md

## 5. นอก MVP (ทำทีหลัง)
โลก 2 (นรก) – 3 (สวรรค์) · ธาตุแพ้ทาง · สกิลกดใช้ (active) ของเผ่า · ร้านบัฟ Rebirth Token · Fuse/Evolve สัตว์ · Daily reward · Quest · Leaderboard · Trading · Gamepass/Dev Product (ช่องทีมเพิ่ม) · Roblox Group
